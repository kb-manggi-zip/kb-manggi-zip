# PART 0. 헌법 (모든 세션 상시 컨텍스트)

## 0-1. 절대 원칙
1. **숫자는 도구(순수 Python 함수)가 계산한다.** LLM은 라우팅·통역·문서읽기만. LLM 출력의 숫자는 입력 facts와 대조 검증하며, 불일치 시 재생성 2회 → 템플릿 폴백.
2. **API 계약 = 프론트 types.ts.** 응답 스키마를 임의 변경하지 않는다. 변경이 필요하면 중단하고 사람에게 보고.
3. **규정 수치는 rules/*.yaml에서만.** 하드코딩 금지, 각 항목에 source_url·checked_at 필수. 값은 프론트 rules.ts와 동일하게 시작(예시값), "# TODO 검증" 유지.
4. **모든 외부 API 응답은 파일 캐싱**(cache/, key=함수명+파라미터 해시). 데모는 캐시만으로 완주 가능해야 한다.
5. **권유 금지 가드레일:** LLM 출력 후처리에서 "추천합니다/하세요/가입하세요/이득/무조건/확실" 패턴 차단 → 재생성.
6. 실패는 정직하게: 데이터 없으면 "확인 불가" 필드로. 추정으로 채우지 않는다.

## 0-2. 스택 & 구조 (변경 금지)
Python 3.11 · FastAPI · Pydantic v2 · LangGraph · Claude API · PublicDataReader · FAISS · Langfuse · Docker(Railway 배포)

```
backend/
├── app/
│   ├── main.py                  # FastAPI + CORS(Vercel 도메인)
│   ├── schemas.py               # Pydantic — 프론트 types.ts 1:1 이식

│   ├── tools/                   # 순수 계산·조회 (LLM 없음)

│   │   ├── dates.py             #   D-day·통보기한

│   │   └── kbland.py            #   KB데이터허브 @cached
│   ├── agents/                  # LLM 노드 (Phase B4부터)
│   │   ├── briefing.py          #   비교표 통역 (스트리밍)

├── cache/  ·  Dockerfile  ·  .env.example
```

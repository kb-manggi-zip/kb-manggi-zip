# 페르소나 신호 → 동네 점수 축 매핑 · 근거 전수표 (S2)

> "페르소나의 어떤 신호가, 동네 점수의 어떤 축을, 어떻게 바꾸는가"를 **코드에서 전수 추출**한 표.
> 목적: "페르소나→동네 추리기 논리가 부족하다"는 리뷰에 대한 **근거 인벤토리**. 이 표의 🔴 항목이
> 리서치로 채울 목록이다(리서치는 사람 몫 — 코드는 채우지 않는다).
> 검증 기준: 현재 main 코드(2026-07-29). 코드 변경 없음.

**근거 상태 범례**
- ✅ **출처 있음** — 특정 조사·문서·데이터로 뒷받침(어느 것인지 명기).
- ⚠️ **설계 판단** — 방향/구조는 합리적이나 값은 설계자 판단(사유는 코드 주석에 있음). 배수·임계의 절대크기는 미검증.
- 🔴 **출처 없음** — 정성 서술뿐이거나 `checked_at: null`. **리서치 대상.**
- 본인 진술 유래 조정은 "1위 증거(본인 확정)"라 **✅**로 분류하되, **배수의 크기**(왜 0.5인가)는 별도 열에 설계값으로 표기.

5. (참고·⚠️) note 키워드 배수·점수식 상수(60분/30, peak 10%, density/200, 선호 1.0/0.3)는 **방향은 타당하나 절대크기는 설계값** — 사용자 데이터 축적 후 튜닝 대상.

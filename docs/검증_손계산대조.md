## P1 — 1인·월세·재택

| 갈래 | 코드 출력 | 손계산 | ✓ |
|---|--:|---|:--:|
| 갱신 price | 50,000,000 | 월세는 보증금 유지 = 5천만 | ✅ |
| 갱신 new_monthly | (내부)630,000 | 600,000 × 1.05 = **630,000** (5% 상한) | ✅ |
| 갱신 월부담 | 635,792 | 630,000 + 보증료 5,792 = **635,792** | ✅ |
| **월세→보증금 환산** | 151,578,947 | 600,000 × 12 ÷ 0.0475 = **151,578,947** | ✅ |
| 이사 price | 90,000,000 | 5천만 + min(5천만×0.8=4천만, 2.22억) = **9천만** | ✅ |
| 이사 월부담 | 93,758 | 이자 83,333(=4천만×**2.5%**/12, 버팀목 청년 자격O) + 보증료 10,425 | ✅ |
| 매매 price | 133,333,333 | 자본(3천+5천=8천만) ÷ (1−0.4) = **133,333,333** (LTV 바인딩) | ✅ |

> P1 이사는 **버팀목 청년 2.5%** 적용(소득4천≤5천·보증금5천만≤3억·만35↓ → 자격O). 매매는 생애최초 '모름'이라 무주택 LTV 40% → 자본이 작아 **LTV가 한도를 결정**.

## 🔴 불일치 1건 — 화면 "실질 월 부담" 보증료 이중계산

### 원인 (어느 단계·어느 값·기대 vs 실제)
- **단계**: 프론트 표시 `frontend/src/screens/CompareTable.tsx:255`
  ```tsx
  실질 월 부담: {formatMonthly(branch.monthlyBurden + branch.guaranteeMonthly)}
  ```
- **값**: `compute_compare`의 `monthlyBurden`은 **이미 보증료를 포함**한다.
  - 근거(P1 월세 이사): `monthlyBurden 93,758 = 이자 83,333 + 보증료 10,425` — 즉 보증료 이미 반영됨.
  - `guaranteeMonthly`는 그 **내역(브레이크다운)** 필드지 추가액이 아님.
- **기대 vs 실제**:
  | 케이스 | 화면 "실질"(현재) | 올바른 실질 | 과대 |
  |---|--:|--:|--:|
  | P2 이사 | 774,753 + 55,103 = **829,856** | 774,753 | +55,103 |
  | P2 갱신 | 84,400 + 32,533 = **116,933** | 84,400 | +32,533 |
  | P1 이사 | 93,758 + 10,425 = **104,183** | 93,758 | +10,425 |
  | 매매(전 케이스) | guar=0 → 이중계산 없음 | 정확 | 0 |
- 부수 문제: 같은 카드의 "월 부담 77만 **+ 보증료 6만**" 표기도 오해 유발(77만이 이미 보증료 포함).

### 왜 생겼나 (설계 의도와 코드의 어긋남)
- E2E §3-3은 "이자 41만 → 반환보증까지 넣으면 실질 45만"으로 **monthlyBurden=이자, 실질=+보증료**를 의도.
- 그러나 `compute_compare`는 **monthlyBurden=이자+보증료**(이미 실질)로 구현 → 표시단에서 또 더해 이중계산.

### 수정 방안 (B-2에 따라 **적용 전 보고** — 결정 요청)
- **옵션 A (프론트만, 권장·동치 무영향)**: monthlyBurden을 '실질'로 취급.
  - "실질 월 부담" = `monthlyBurden` 그대로. 필요 시 "이자 {monthlyBurden − guaranteeMonthly} + 보증료 {guaranteeMonthly}"로 분해 표시.
  - `compare.py`/`compare.ts` 미변경 → 동치 테스트 영향 없음.
- **옵션 B (백엔드 의미 변경)**: monthlyBurden=이자만, 실질=+보증료. E2E 문구와 문자 그대로 일치하나 `compare.py`+`compare.ts`+fixtures 재생성 필요(엔진 동치 재검증).

→ **권장: 옵션 A.** 어느 쪽으로 갈지 결정 주시면 반영(옵션 B면 동치 재생성 후 재검증).

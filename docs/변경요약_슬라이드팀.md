## 4. 발표 대비 메모

- **S1 숫자는 이제 재현된다** — 배수가 yaml 고정(방향만 LLM, 크기는 설계값). 리허설에서 본 값이 발표에서도 나온다. "그 0.3은 어디서 나왔죠?" → `axis_adjust.yaml`.
- **"자유입력만으로 계산 안 바뀜"** — 갱신상황은 계약 사실과 `requires` 교차검증. 통보경과라 말해도 만기가 미래(noticeDaysLeft≥0)면 기각(cap 5 유지).
- **확장 경계**(Q&A 답변용, [갱신상황_설계 §6](갱신상황_설계.md)):
  - yaml만으로: cap 효과·안내·근거·priority·기존 사실 키 requires·branch_hint
  - 코드 필요: ① requires 새 사실 키 ② 새 effect 종류 ③ 8번째 enum
- **branchHints**는 상황이 3갈래 각각의 의미를 바꾸는 부분(순위는 안 바꿈, 정보만 붙임).

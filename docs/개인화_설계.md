# 개인화 설계 — 페르소나가 어떻게 만들어지고, 어떻게 결과를 바꾸나

> 이 서비스의 핵심. 가장 검증받는 문서라 **주장 ≤ 코드**를 철저히 지킨다. 근거 강도(✅조사 / ⚠️설계 / 가설)를 항상 병기.
> 전수 매핑은 [페르소나_축매핑_근거표](페르소나_축매핑_근거표.md), 출처 총괄은 [선행연구_근거체계_총괄표](선행연구_근거체계_총괄표.md).

## 1. 페르소나 조립 흐름

```mermaid
flowchart LR
  Q["문진(숫자+자유입력)"] --> S["③ 세그먼트 기본값<br/>(가구유형→traits·가중치)"]
  S --> M["② 실측 override<br/>(마이데이터 ±30%)"]
  M --> ST["① 진술 해석(LLM)<br/>→ 4축 배수 제안"]
  ST --> H["HITL 확정<br/>(사용자 확인)"]
  H --> PF["최종 PersonaProfile<br/>(weights·consumptionSignals)"]
```

각 단계는 **출처 태그**를 달고 합쳐진다(진술/실측/세그먼트). 화면엔 "당신은"(진술·실측) vs "이 세그먼트는"(세그먼트)로 구분 표기.

## 2. 증거의 위계 — 강한 증거가 약한 증거를 덮어쓴다

> **① 본인이 말한 것(진술) > ② 실제 소비 기록(실측) > ③ 가구 유형 평균(세그먼트)**

| 순위 | 레이어 | 예 | 출처 | 반영 조건 |
|---|---|---|---|---|
| 1 | 진술 | "재택이라 통근 덜 중요" | 본인 한 줄 + LLM 해석 + **본인 확인** | HITL 확정 시만 |
| 2 | 실측 | "카페 지출이 또래의 0.6배" | 마이데이터(시연: 합성) | 또래 대비 **±30% 편차**일 때만 override |
| 3 | 세그먼트 | "이 연령대는 배달·구독↑" | 경기 카드소비 집계 | 위 둘이 없을 때 기본값 |

세그먼트를 **개인의 사실처럼 위장하지 않는다** — 화면에 출처를 구분해 표기.

## 3. 페르소나 → 축 반영 매핑 (요약)

| 신호 | 반영 | 값 | 근거 강도 |
|---|---|---|---|
| 세그먼트 1인 청년 | commute | ×1.3 | ✅ 청년의삶 조사(통근 39.2% 1위) |
| 세그먼트 신혼 | budget·commute | ×1.3 / ×1.15 | ✅ 주거실태 표36 + 표10·11 실측 |
| 세그먼트 자녀 | preference·consumption | ×1.3 / ×1.2 | ⚠️ 설계(학군·인프라 서술) |
| 진술 "재택" | commute·consumption | ×0.5 / ×1.3 | ✅ 진술(1위 증거) / 배수 ⚠️ 설계 |
| 진술 "학교·학군" | preference | ×1.3 | ✅ 진술 / 배수 ⚠️ 설계 |
| 실측 `values_food` | consumption 점수 게이트 | ±30% 임계 | ⚠️ 설계값(`checked_at: null`) |

LLM 해석은 **4축·배수 0.3~2.0**으로 제약, 벗어나면 키워드 폴백. 전수는 [매핑근거표](페르소나_축매핑_근거표.md).

## 4. 동네 스코어링 + crosswalk

**0단계 예산 하드필터**(예산 초과 동네 제외) → 통과 후보를 **4축 가중합**으로 순위:
`동네점수 = Σ 가중치[축] × 점수[축]`

점수식(전부 투명한 순수 함수): 통근 `(60−분)/30` · 예산 종형(여유 10% 최고점) · 생활소비 `상권밀집도(min(dc/200,1)) × 소비성향` · 선호지역 `선호구 1.0 / 아님 0.3 / 미지정 0.6`.

### crosswalk — 조사 원문 항목 → 축 → 가중치 (W1 확정, 4축 전부 원문)

출처: **2024 주거실태조사 통계보고서 <표 10> '현재 주택으로 이사한 이유'**(전국·복수응답 %).

| 축 | 원문 항목 | 응답률 | 정규화 가중치 |
|---|---|---|---|
| 통근 | 직주근접·직장 변동 때문에 | 30.6% | **40.5%** |
| 생활·소비 | 교통이 편리하고, 편의·문화시설, 공원·녹지 등이 좋은 지역 | 25.5% | **33.8%** |
| 선호지역 | 부모·자녀 근접(8.1) + 자녀 양육·교육환경(3.0) | 11.1% | **14.7%** |
| 예산 | 집값·집세가 너무 비싸고 부담 | 8.3% | **11.0%** |

**배제 항목(어느 축에도 매핑 안 함)**: 시설·설비 양호(47.2)·규모 적합(20.3)=**주택 내부 속성**(집을 채점 안 함) / 계약만기·통보·재개발=**비자발적 이사**(문제정의 근거로만) / 결혼·내집마련·귀농=**생애 이벤트**(PoC 밖).

> **정직성 기록(W1)**: 과거엔 25.5%를 '교통 편리'로 읽어 통근에 합산(56.1%)했으나, 원문 항목은 교통·편의·녹지가 묶인 **복합 생활환경**이라 통근 전용이 아님 → 생활·소비로 재매핑. 이후 예산·선호도 원문값으로 승격해 **4축 전부 원문 확정.**

## 5. 개인화가 결과를 바꾸는 실증 (S1, 실행값)

입력: **1인 청년 · 성북구 · 이사 예산 5.02억** · 자유입력 **"재택근무예요"** 확정

| | top 3 |
|---|---|
| 재택 확정 **전**(또래 평균) | 1.동선동1가 · 2.동선동4가 · 3.동소문동4가 |
| 재택 확정 **후**(통근↓·상권↑) | **1.동선동4가** · 2.동소문동4가 · 3.동선동1가 |

→ 재택 확정 시 통근 가중치 **40.5% → 27%**로 내려가고, 상권 실측이 풍부한 동(동선동4가 카페 316곳)이 1위로 **뒤바뀐다.** "한 줄이 순위를 바꾼다"의 실제 증거.

## 6. 정직한 한계 (감추면 Q&A에서 뚫린다)

- **소비→개인 중요도 추정**은 **명시된 가설**(총괄표 §3-1 C층). 생활·소비 축은 "**무게=조사 / 개인 조정=가설**"로 구분한다.
- **소비→동네 반영은 식음료 축 중심**(장보기·여가는 수집돼 있으나 점수 반영은 로드맵).
- **마이데이터는 합성** 3 페르소나(P1/P2/P3). **자녀 지출 페르소나는 부재** → 자녀 프리셋(P4)의 지출 분석은 P1로 매핑(데모 한계).
- **개인화 순위 변화는 후보 동에 통근·상권 실측이 있을 때** 뚜렷. 실측 없는 동으로만 채워지는 예산대에선 덜 움직인다(데이터 커버리지 의존).
- 세그먼트/note 배수·점수식 상수(통근 60분 컷 등)는 **방향은 타당하나 절대크기는 설계값** — 사용자 로그 축적 후 튜닝 대상.

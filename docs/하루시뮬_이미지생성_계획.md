# 하루시뮬(SC-07) 씬 이미지 생성 계획

> 초안 — 팀 확인 후 실행(비용이 한 번에 나가는 배치라 사전 합의 필요)

## 뭘 만드는가

SC-07 "하루시뮬"은 지금 화면 틀만 있고 5개 시간대 씬을 Unsplash **스톡사진**으로 채운 가라 상태(갈래 3개끼리도 같은 사진 재사용, 지역 커스텀은 82개 동 중 3개뿐). 이걸 **동네마다 실제로 다른 AI 생성 이미지**로 바꾸는 계획.

## 핵심 아이디어 — "그림 내용"과 "보여주는 순서"를 분리

- **그림 내용 = 동 기준**: 그 동이 가진 태그(카페거리·마트편의점밀집·여가시설밀집·학원가·초역세권·공원인접)를 반영해서 동마다 다른 이미지
- **보여주는 순서/개수 = 사람 기준**: 이 사람이 뭘 중시하는지(통근/소비/예산/선호지역 — 이미 계산돼있는 값)에 따라 어떤 씬을 먼저·크게 보여줄지만 결정. **추가 이미지 없이 순서만 바꾸는 거라 비용 0원.**

나누는 이유: 사람 기준으로만 정하면 같은 사람이 보는 후보 동 3개가 다 똑같아 보임. 동 기준으로만 정하면 이 사람한테 뭐가 중요한지 반영이 안 됨. 그래서 그림은 동마다, 순서는 사람마다 다르게 — 둘 다 해결.

## 씬 카테고리 5개 (태그 매핑)

| 카테고리 | 매칭 태그 | 없으면 |
|---|---|---|
| 🌅 통근 | 초역세권 | 골목길 걷는 장면 |
| ☕ 카페 | 카페거리 | 카페 한 곳 |
| ☀️ 공원 | 공원 인접 | 일반 식당가 |
| 🌇 마트 | 마트·편의점 밀집 | 저녁 골목 |
| 🌙 집 | 학원가·여가시설(배경만) | 일반 주거지 |

동이 가진 태그 수만큼만 노출(고정 5 아니고 2~5개 가변). 예산·선호지역 축은 이미지로 안 만듦 — 예산은 SC-08(아낀돈)이, 선호지역은 "그 동을 골랐다"는 사실 자체가 이미 담당.

## 스코프·비용

**82개 동 × 5카테고리 = 410장.** 갈래(이사/매매/갱신)·가구유형은 공용(이미지 안 나눔) — 갈래는 지금도 같은 사진 재사용 중이라 문제없고, 가구유형별로 나누면 비용이 3~4배 뜀(개인화는 위 "순서" 로직 + 기존 텍스트 내레이션이 이미 담당하므로 불필요).

| 스코프 | 장수 | 비용 |
|---|---|---|
| **채택안**(공용) | 410 | 약 2.2만원 |
| 자녀유무만 2분기 (검토용) | 820 | 약 4.4만원 |

1회성 비용, 표준 요율 기준.

## 이미지엔 랜드마크 이름 안 넣음

"합정역"이라고 프롬프트에 넣어도 실제 합정역은 안 그려짐 — 가짜를 진짜처럼 보이게 하는 셈이라 금지. 이미지는 계속 일반화된 분위기만. **캡션(텍스트)에 실제 역·공원 이름을 넣을지는 미정**(지금 3개 동 커스텀 씬은 이미 그렇게 함) — 다만 그 이름 데이터는 어차피 카카오 API 호출하는 김에 지금 저장해두는 게 나음(안 해두면 나중에 또 API 불러야 함).

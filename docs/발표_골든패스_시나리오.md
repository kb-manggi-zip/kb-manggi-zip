# 발표 골든패스 & 완주 시나리오 (코드로 검증됨)

> ⚠️ 상상 아님 — **현재 코드·데이터로 실제 끝까지 도는 경로만** 기재. (검증일 2026-07-27, 데이터=trades.demo.db 64,431건 + 상권 27집계)
> 재현: `backend`에서 각 페르소나로 `compute_compare` → `regions_by_branch` → `matcher.run` → `narrate_lifestyle`.

## 1. 완주 매트릭스 (진입→비교→동네→발품→금융→저장)

| 페르소나 | 계약 | 갱신 | 이사 | 매매 | 막히는 지점 |
|---|---|---|---|---|---|
| **P1 청년**(전세2억·소득4천·자본3천·1인) | 전세 | ✅ | ✅ | ✅ | — (매매 동네: 동소문·방학·도봉동) |
| **P2 신혼**(전세3.2억·소득8천·자본6천·생애최초) | 전세 | ✅ | ✅ | ✅ | — (규제3겹·디딤돌 다 보임) |
| **P3 월세**(월세2천/80·소득5.5천·자본1.5천·빌라) | 월세 | ✅ | ✅ | 🟡 계산O·**동네후보 없음** | 매매 예산 1.58억 → 서울 6구에 살 아파트 없음(현실적). **데모는 P3 이사 사용** |

→ **7/8 경로 완주.** P3 매매만 "동네 없음"(저자본 청년의 서울 매매 비현실 = 정직한 결과, 데모 회피).

## 2. 계산 계보 — 골든패스 메인 (P2 신혼·매매) ★

실제 실행값 (코드 재현):
```
[입력]  연소득 8천 / 자본 6천 / 전세보증금 3.2억 / 생애최초 '예' / 만35세미만 / 신혼   ← SC-02 store
   ↓
[자본]   6천 + 3.2억(보증금 회수) = 3.8억
[LTV]    생애최초·규제지역 → 70%                              ← lending_regulated.yaml::ltv
[DSR]    40% + 스트레스 3.0%(수도권규제) → 산정금리 7.1%       ← lending_regulated.yaml::dsr
[디딤돌] 신혼·무주택·소득8천≤8.5천 → 자격O, 한도 3.2억, 2.85%  ← policy_loans.yaml::didimdol
[캡]     min(LTV한도, DSR한도, KB 3억, 정부 6억)               ← mortgage_cap
   ↓ solve_max_price (tools/lending_calc.py)
[최대 집값]  7억 7,681만
[월 상환]    1,694,512원 (디딤돌 2.85% + KB 4.10% 혼합, 표시용 base)  ← annuity_payment
[취득세]     생애최초 감면 반영(지방세법 §11 구간 + -200만)     ← one_time.yaml / lending_regulated
   ↓
[동네]  regions(매매, budget=7.77억) → 동선동1가·상월곡동·삼선동4가  ← trades.db sale 실거래, 예산근접순
   ↓
[발품]  narrate_lifestyle(P2, 신혼, 매매, 동네)
        상권(마트·음식·여가 실집계) + 통근(여의도 근무 시 약 N분, 조건부) + 실거래(전용 60㎡ 11.8억, 국토부)
   ↓
[금융]  products(매매) → KB 주택담보대출 + 화재보험 + 청약종합저축   ← data/kb_products/*.md
   ↓
[저장]  상담예약 (reservation)
```
- 근거칩(화면): `규제지역 LTV 70%` · `KB 한도 3억` · `스트레스 DSR 가산 3.0%` · `디딤돌 혼합`.
- **"이 숫자는 이 근거"가 전부 파일로 추적됨** → 심사 신뢰.

## 3. 골든패스 추천

### 🥇 메인: P2 신혼 · 매매 (~2분)
- **왜 강한가**: 규제3겹(LTV·스트레스DSR·캡) + 디딤돌 + 생애최초 감면 + 통근·상권·실거래 발품이 **한 경로에 다 나옴**. "만기 → 내 집 7.7억 → 이 동네에서의 삶 → KB 금융"이 관통.
- **클릭 순서**: SC-01(D-96) → SC-02(데모 데이터 P2) → SC-03 비교표(3갈래·근거칩) → SC-04 동네(동선동1가) → SC-07 하루(발품: 여의도 통근+상권+실거래) → SC-09 금융(디딤돌+주담대) → SC-10 예약.
- **하이라이트**: 비교표 근거칩 · 발품의 "여의도로 통근한다면 46분 + 전용 60㎡ 11.8억 실거래".

### 🥈 서브: P3 월세 · 이사(전세 갈아타기) (~1.5분)
- **왜**: 다른 갈래·다른 감정("월세 탈출 → 전세"). 저자본 청년 공감. 발품(판교 통근 가정).
- 주의: **P3 매매는 쓰지 말 것**(동네후보 없음).

### 대안 서브: P1 청년 · 갱신 (아낀 돈 서사)
- 눌러앉기 → 이사비·중개비 0원 "아낀 돈" 카드. 만기 급성감 + 절약 감정.

## 4. 데모 리스크 점검
| 항목 | 상태 |
|---|---|
| 오프라인 완주 | ✅ 계산=결정론, 동네=trades.demo.db, 발품=LLM **폴백 템플릿**(LLM off도 완주) |
| LLM 실패 폴백 | ✅ `generate`가 실패·부적합 시 템플릿 반환 |

| 통근시간 | 🟡 키 없으면 "예상치(조건부)" — 발표 시 "실서비스는 ODsay 실측" 멘트 |

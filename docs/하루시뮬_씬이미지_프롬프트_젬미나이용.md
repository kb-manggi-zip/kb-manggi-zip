# 하루시뮬 씬 이미지 프롬프트 (제미나이 수동 생성용)

`backend/scripts/generate_scene_images.py`가 생성하는 프롬프트 16개 전문. API 결제 없이
제미나이 채팅창에 하나씩 붙여넣어 이미지를 만들 때 씀 — 소스는 스크립트이고 이 파일은 그
출력을 복붙하기 편하게 옮겨둔 것(스크립트가 바뀌면 다시
`.venv/bin/python3 scripts/generate_scene_images.py --print`로 재생성해서 갱신할 것).

**2026-08-02 세로 비율 추가**: 앱 화면이 세로 풀스크린(390px 폭, `object-cover`)인데 처음
만든 15장이 다 가로형(1408×768)으로 나와서 가운데 세로 슬라이스만 남고 양옆이 심하게 잘림
(가로 폭의 약 25%만 보임). `_COMMON`에 "세로 9:16 비율" 지시를 추가했음 — **기존에 만든
이미지는 전부 이 프롬프트로 다시 만들어야 함.** 한 번에 다 돌리기 전에 `cafe_day_0.png`
(원래 안 만들었던 것) 하나로 먼저 테스트해서 제미나이가 세로 비율을 실제로 지키는지 확인
권장.

간판 글자는 완전히 안 보이게(빈 간판판/각도로 가려짐) 처리하고, 대신 업종은 러닝머신·음료
냉장고·학원 통학버스 같은 구체적 사물로 알아보게 했음(글자를 시도했다가 부자연스러워서 되돌림).

각 항목을 프롬프트 그대로 제미나이에 보내고, 받은 이미지는 표시된 파일명으로 저장해서
`backend/data/scene_images/`에 넣으면 됨.

포토리얼리스틱 사진, 자연스러운 다큐멘터리 스트리트 포토(필름 그레인·빈티지 필터 없음). 세로 9:16 비율의 세로 사진(휴대폰 세로 화면 꽉 채움, 가로로 넓은 사진 아님) — 카메라가 피사체에서 충분히 뒤로 물러난 와이드 구도로, 위로는 건물 상단까지, 아래로는 인도·도로까지 세로 프레임 안에 다 들어오게. 밝고 깨끗한, 최근 지어지거나 리모델링된 저층~중층(3~5층) 한국 상가 건물. 눈높이 카메라 앵글, 자연스러운 구도. 간판·안내판의 글자·로고·브랜드명은 전혀 보이지 않게(빈 간판판이거나 각도로 가려짐) — 단, 업종을 한눈에 알아볼 수 있는 사물·집기·구조물은 또렷하게 보이게 유지(글자를 없앤다고 업종 정체성까지 흐려지면 안 됨). 낡거나 벗겨진 벽돌, 색바랜 페인트, 오래된 간판 서체, 빈티지 느낌, 좁고 어두운 골목(일본식 좁은 상점가 느낌) 없음. 사람 없음. 작은 학원들이 여러 층에 입주한 저층~중층 건물이 늘어선 거리 — 하원 시간대라 거의 모든 층 창문에 불이 켜져 북적이는 느낌, 건물 앞엔 노란색 학원 통학버스 한 대가 다시 정차해 있음. 주황빛으로 물든 노을 하늘, 그림자가 길고 따뜻한 색조, 가로등과 상점 조명이 켜져있음.

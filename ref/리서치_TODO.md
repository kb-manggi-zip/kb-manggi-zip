## ① 페르소나 근거 수치 뽑기 (주거실태조사)

**왜:** 우리 가상 페르소나(P1 청년·월세 / P2 신혼·전세 / P3 청년·전세)의 보증금·소득이 "지어낸 값"이 아니라 국가 통계에 앵커된 값이어야 함. 발표에서 "페르소나는 국토부 주거실태조사에서 도출했다"고 말할 근거.

**어떻게:**
1. 국토교통 통계누리에서 「2024년도 주거실태조사」 연구보고서 PDF 다운로드
2. 특성가구(청년/신혼) 챕터에서 다음 수치 발췌:
   - 청년·신혼 가구의 평균/중위 임차보증금, 월세, 소득
   - 점유형태 비율 (청년 임차 82.6%, 자가점유 12.2% — 보도자료엔 이미 확인됨, 보고서 원문 페이지 번호 찾기)
   - 희망 주거지원 프로그램 순위 (청년=전세대출, 신혼=구입대출)
   - 주거환경 만족도 **평가 항목 목록** (교통·편의시설·교육환경 등) ← 동네 태그 근거로 쓸 예정
3. 각 수치에 보고서 페이지 번호까지 기록
4. 우리 페르소나 3종의 보증금·소득이 이 통계 범위 안에 있는지 대조 → 벗어나면 표시

**출처:**
- 국토교통 통계누리 (주거실태조사): https://stat.molit.go.kr/portal/cate/statMetaView.do?hRsId=327
- 보도 요약 참고: https://www.hkbs.co.kr/news/articleView.html?idxno=810847
- 보조 통계: KOSIS(kosis.kr) 가계금융복지조사 — 연령대별 소득·자산 분위

**산출물(예시):**  `research/persona_근거.md` + 보고서 PDF

## ② 문진 구간 경계값 맞추기

**왜:** 문진의 소득/자산 구간("3~5천" 등)이 임의 구간이 아니라 **정책대출 자격 경계**와 일치해야 계산이 정확해짐. 예를 들어 디딤돌대출 소득 상한이 구간 경계에 걸리면 자격 판정이 틀어짐.

**어떻게:**
1. 주택도시기금에서 디딤돌·버팀목(+청년·신혼 전용) 상품별 **소득 상한 / 주택가액 상한 / 대출 한도 / 금리** 표로 정리
2. 우리 문진 구간(연소득: 3천↓/3~5천/5~7천/7천↑)이 이 경계들과 어긋나는지 확인 → 어긋나면 조정안 제안
3. 각 상품의 자격 조건(무주택, 가구형태 등)도 함께 표로

**출처:**
- 주택도시기금: https://nhuf.molit.go.kr (개인상품 → 주택구입/전세자금)
- 기금e든든(신청 실무 기준): https://enhuf.molit.go.kr

**산출물(예시):** `research/정책대출_요건표.md`

## ③ 공적 계산기 대조 검증

**왜:** 우리 예산·월상환 계산이 맞다는 걸 "공식 계산기와 같은 결과가 나온다"로 증명. 산식 자체의 근거가 됨. 스크린샷이 곧 증거 자료.

**어떻게:**
1. 우리 앱에서 P2 페르소나로 계산 → 대출액·금리·기간·월상환액 기록
2. 같은 조건(대출액/금리/30년/원리금균등)을 아래 계산기 2곳에 입력
3. 월 상환액이 일치하는지 확인 (오차 있으면 원 단위 반올림 차이인지 확인, 그 이상 차이면 슬랙 공유)
4. **양쪽 스크린샷 저장** (입력값과 결과가 한 화면에 보이게)

**출처:**
- 주택금융공사 금융계산기: https://www.hf.go.kr (금융계산기 메뉴)
- 금융감독원 금융상품한눈에: https://finlife.fss.or.kr (대출 → 월평균 상환액 산출 방식 설명 페이지도 캡처)

**산출물(예시):** `research/계산검증_대조.md` + 스크린샷 4장 이상

## ④ 전세대출 금리 최신값 확인

**왜:** 코드의 전세대출 금리 3.8%는 잠정값. 공시 기반 실제 평균으로 교체해야 함. 매주 바뀌니 확인일 기록이 특히 중요.

**어떻게:**
1. HF 전세대출금리 주별 공시에서 최신 주간의 **은행 평균금리** 확인 (KB국민은행 값도 따로 기록)
2. 은행연합회에서 전세자금대출 평균금리 교차 확인
3. 두 값이 다르면 둘 다 기록하고 어떤 걸 쓸지 슬랙에서 결정

**출처:**
- HF 주별 공시: https://www.hf.go.kr/ko/sub02/sub02_01_07_01.do
- 은행연합회 소비자포털: https://portal.kfb.or.kr/compare/loan_household_new.php

**산출물(예시):** `research/금리_확인.md` (값 + 취급기간 + 캡처) → 확인되면 rules yaml의 jeonseRate 교체 요청

## ⑤ HUG 보증료율 구간표 확보

**왜:** 현재 코드는 대표값 하나(0.13~0.15%)만 쓰는데, 실제는 보증금 구간(1억↓/1~2억/2~5억/5~7억) × 전세가율별 차등. 구간표를 확보해야 페르소나별로 정확한 요율 적용 가능. UI의 "연 0.097~0.211%" 범위 표기 근거이기도 함.

**어떻게:**
1. HUG 홈페이지에서 전세보증금반환보증 **보증료율 표 원본** 찾기 (2025.3.31 개편 이후 버전인지 확인 — 0.097~0.211% 범위면 최신)
2. 표 전체를 캡처 + 셀값을 md 표로 옮기기
3. 우리 페르소나 3종이 각각 어느 구간에 해당하는지 매핑

**출처:**
- HUG: https://www.khug.or.kr (개인보증 → 전세보증금반환보증 → 보증료 안내)
- 개편 배경 참고: https://www.nongmin.com/article/20250219500542

**산출물(예시):** `research/보증료율표.md`

## ⑥ 규제지역·LTV 현행 확인

**왜:** 규제지역 지정은 수시로 바뀌고, LTV·6억 캡이 우리 매매 계산의 핵심 변수. 코드의 규제지역 50%·수도권 캡 6억이 현행과 맞는지 원문 확인 필요.

**어떻게:**
1. 금융위원회 보도자료에서 「가계부채 관리방안(2025.6.27)」 원문 PDF 다운로드 → LTV 비율표·주담대 한도(6억) 부분 캡처
2. 그 이후 추가 대책이 있었는지 보도자료 목록에서 확인 (있으면 최신 기준으로)
3. 현재 규제지역(조정대상지역·투기과열지구) 지정 목록 확인 — 국토부 고시
4. 스트레스 DSR 비수도권 하한 현행값도 같은 자료들에서 확인 (수도권 3.0%는 확인됨)

**출처:**
- 금융위원회 보도자료: https://www.fsc.go.kr (보도자료 검색: "가계부채")
- 국토부 규제지역 고시: https://www.molit.go.kr
- 참고(정리 잘 된 은행 공식 자료): https://kbthink.com/loan-guide/stressdsr.html

**산출물(예시):** `research/대출규제_현행.md` + 보도자료 PDF

## ⑦ 금소법 권유 규제 확인 + 문구 점검
> 얘는 사실 딱히 필요 없긴 한데 상품 추천을 유도하면 안돼서 참고하면 좋을 것 같아 넣은 항목이에요. 뭔지만 인지하시고 가이드 해주시면 될듯

**왜:** 금융상품을 "추천"하면 금융소비자보호법의 판매권유 규제에 걸릴 수 있음. 우리는 정보제공형으로 설계했는데, 그 경계가 되는 조항을 원문으로 확인해두면 발표 때 "규제를 인지하고 설계했다"고 말할 수 있음 (금융사 심사위원에게 가점 포인트).

**어떻게:**
1. 국가법령정보센터에서 「금융소비자 보호에 관한 법률」 검색 → 판매권유 정의, 적합성 원칙, 광고 관련 조항 번호와 요지 정리 (법 전문 분석까지는 불필요 — 조항 존재와 취지 수준)
2. 금융위 금소법 안내자료·FAQ 있으면 함께 저장
3. 우리 앱 화면 문구 전수 점검: "추천/골랐어요/가입하세요/유리해요" 류가 남아있는지 → 목록으로 정리 (수정은 개발에서)

**출처:**
- 국가법령정보센터: https://www.law.go.kr → "금융소비자 보호에 관한 법률"
- 금융위원회 금소법 안내: https://www.fsc.go.kr

**산출물(예시):** `research/금소법_체크.md` + 문구 수정 대상 목록

## ⑧ KB 상품 정보 정리 (RAG 소스)

**왜:** 상품 매칭(RAG)의 원천 데이터. 금리·한도를 LLM이 지어내면 안 되니까 **공시 원문 그대로** 옮겨야 함. 파일마다 출처 URL이 있어야 "출처 있는 DB"가 됨.

**어떻게:**
1. KB국민은행 상품 페이지에서 아래 5~8개 상품의 공시 정보 확인:
   - KB 주택담보대출 / KB 전세자금대출(HUG·HF 보증부) / 디딤돌·버팀목(기금 위탁) / 청년 전용 상품 / 주택청약종합저축
2. 상품마다 md 파일 1개: 상품명 / 대상 / 한도 / 금리(확인일 기준) / 우대 조건 / source_url / 조회일
3. 금리·한도 숫자는 **원문 표현 그대로** (반올림·요약 금지)
4. 은행연합회 비교공시에서 해당 상품 금리도 교차 기록

**출처:**
- KB국민은행 상품공시: https://obank.kbstar.com (상품 안내·금리 공시)
- 은행연합회: https://portal.kfb.or.kr
- 기금 상품 원 요건: https://nhuf.molit.go.kr

**산출물(예시):** `data/kb_products/*.md` 5~8건

## ⑨ 중개보수 별표 원문 + 서울시 조례

**왜:** 코드의 중개보수 구간표가 시행규칙 [별표1] 그대로인지 원문 대조 필요. 실제 적용 요율은 지자체 조례로 확정되므로 서울시 조례도 확인 (데모 지역이 서울이라).

**어떻게:**
1. 국가법령정보센터 → 「공인중개사법 시행규칙」 → [별표1] 원문 캡처
2. 코드의 구간표(매매 6구간·임대차 6구간·한도액)와 셀 단위 대조 → 다르면 표시
3. 월세 환산 규칙(보증금+월세×100, 5천만 미만 시 ×70) 조문 위치 확인
4. 서울시 중개보수 조례에서 상한요율과 동일한지 확인

**출처:**
- 국가법령정보센터: https://www.law.go.kr → "공인중개사법 시행규칙" → 별표/서식
- 서울시 조례: https://legal.seoul.go.kr → "주택 중개보수" 검색

**산출물(예시):** `research/중개보수_대조.md`

## ⑩ 취득세 + 생애최초 감면 확인

**왜:** 매매 갈래 일회성 비용의 근거. 특히 생애최초 감면(최대 200만원)은 일몰 기한이 있는 제도라 **현재 유효한지**가 핵심 확인 사항.

**어떻게:**
1. 국가법령정보센터 → 「지방세법」 제11조에서 1주택 유상취득 세율 구간(6억↓ 1% / 6~9억 선형 / 9억↑ 3%) 원문 확인
2. 「지방세특례제한법」에서 생애최초 취득세 감면 조항 → **적용 기한(일몰)과 조건(주택가액 상한 등)이 현재 유효한지** 확인
3. 위택스 취득세 계산기로 P2 페르소나 케이스 1건 대조 계산 + 캡처

**출처:**
- 국가법령정보센터: https://www.law.go.kr → "지방세법", "지방세특례제한법"
- 위택스: https://www.wetax.go.kr (지방세 미리계산)

**산출물(예시):** `research/취득세_확인.md` + 위택스 캡처
